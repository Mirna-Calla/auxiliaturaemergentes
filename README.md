# Práctica React - Fundamentos para Next.js

## Objetivos
- Comprender los conceptos básicos de React como librería de construcción de interfaces
- Migrar una aplicación en JavaScript hacia un entorno React
- Introducir el flujo de trabajo con Next.js como evolución natural de React
- Familiarizarse con las herramientas necesarias para el desarrollo moderno

## Estructura del Proyecto

### Capítulo 1: JavaScript Puro
- **Ubicación**: `chapter-1/`
- **Tecnologías**: HTML, CSS, JavaScript puro
- **Conceptos**: Manipulación del DOM, Local Storage, Eventos
- **Ejecutar**: Abrir `chapter-1/index.html` en el navegador

### Capítulo 2: React
- **Ubicación**: `chapter-2/todo-react/`
- **Tecnologías**: React, Hooks (useState, useEffect)
- **Conceptos**: Componentes funcionales, Props, Estado, JSX
- **Ejecutar**: `cd chapter-2/todo-react && npm start`

### Capítulo 3: Next.js
- **Ubicación**: `chapter-3/todo-nextjs/`
- **Tecnologías**: Next.js 14, TypeScript, Tailwind CSS
- **Conceptos**: App Router, Server/Client Components, SSR/SSG
- **Ejecutar**: `cd chapter-3/todo-nextjs && npm run dev`
