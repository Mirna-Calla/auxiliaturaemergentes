# Capítulo 1: JavaScript Puro

## Conceptos Aprendidos

### 1. Manipulación del DOM
- **document.getElementById()**: Para seleccionar elementos del DOM
- **element.addEventListener()**: Para manejar eventos del usuario
- **element.innerHTML**: Para modificar el contenido HTML
- **document.createElement()**: Para crear elementos dinámicamente

### 2. Gestión de Estado
- **Array de tareas**: Almacenamos el estado en un array de objetos
- **Local Storage**: Persistencia de datos en el navegador
- **Métodos de array**: filter(), map(), forEach() para manipular datos
