# Capítulo 3: Migración a Next.js

## Conceptos de Next.js Aprendidos

### 1. App Router (Nuevo en Next.js 13+)
- **Estructura de Archivos**: Sistema de enrutamiento basado en carpetas
- **page.tsx**: Componente de página por defecto
- **Layouts**: Diseños reutilizables entre páginas

### 2. Server Components vs Client Components
- **'use client'**: Directiva para componentes del lado del cliente
- **Renderizado Híbrido**: Combinación de server-side y client-side
- **Streaming**: Renderizado progresivo

### 3. TypeScript Integration
- **Tipado Estático**: Detección de errores en tiempo de desarrollo
- **Interfaces**: Para definir la forma de los objetos
- **Type Safety**: Mayor confiabilidad del código

### 4. Tailwind CSS
- **Utility-First**: Enfoque de clases utilitarias
- **Responsive Design**: Clases para diferentes breakpoints
- **Dark Mode**: Soporte integrado para modo oscuro

### 5. Optimizaciones de Next.js
- **Image Optimization**: Componente Image optimizado
- **Font Optimization**: Carga optimizada de fuentes
- **Bundle Analysis**: Análisis del tamaño del bundle

## Características Avanzadas de Next.js

### Ventajas sobre React puro:
- ✅ **Renderizado del Lado del Servidor (SSR)**
- ✅ **Generación de Sitios Estáticos (SSG)**
- ✅ **API Routes integradas**
- ✅ **Optimización de Imágenes Automática**
- ✅ **Mejor SEO por defecto**
